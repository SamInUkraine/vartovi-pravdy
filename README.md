# Сервер перевірки відповідей

Невеликий сервер на Cloudflare Workers (безкоштовний тариф). Він зберігає ключ Gemini,
перевіряє відповіді гравців і рахує ліміти. Сам ключ у гру **не потрапляє**.

## Як він захищає ключ
- Ключ зберігається як секрет Cloudflare (`GEMINI_API_KEY`). Його немає ні в грі, ні в коді.
- Гра надсилає тільки колоду, номер картки й текст відповіді. Промпт і еталонні відповіді
  лежать на сервері, тому через нього не можна «поговорити» з Gemini на будь-яку тему.
- Обмеження для одного пристрою: 6 перевірок за хвилину і 150 за добу.
- Спільний денний ліміт на модель (450 для 3.5 і 450 для 3.1) трохи нижчий за ліміт Google.
  Якщо Google все ж поверне 429, модель вимкнеться до скидання ліміту, а перевірка перейде на іншу.
- Максимальна довжина відповіді — 1500 символів.
- Gemini викликається з вузла в США, бо з європейських вузлів Google часто відповідає
  «User location is not supported».

## Розгортання (~10 хвилин)
Потрібен Node.js 18+.

```bash
cd server
npm install
npx wrangler login                      # відкриється браузер — увійдіть у Cloudflare (безкоштовний акаунт)
npx wrangler secret put GEMINI_API_KEY  # вставте ключ з aistudio.google.com
npx wrangler deploy
```

Після `deploy` з'явиться адреса, наприклад `https://vartovi-gemini.ІМ'Я.workers.dev`.
Перевірте, що все працює: відкрийте в браузері `https://…workers.dev/status`. Має бути `"ai":true`.

## Підключення до гри
У файлі гри знайдіть рядок
```js
const AI_URL='';
```
і впишіть між лапками адресу сервера (без `/` у кінці). Файл гри великий (~47 МБ), тому
звичайний редактор може тормозити. Можна просто надіслати адресу — і я вставлю її сам.

## Додатковий захист ключа в Google
Google Cloud Console → APIs & Services → Credentials → ваш ключ → **API restrictions** →
залиште лише **Generative Language API**. Тоді навіть у разі витоку ключ не підійде для інших сервісів Google.

## Налаштування (`wrangler.toml`, розділ `[vars]`)
| Змінна | За замовчуванням | Що робить |
|---|---|---|
| `RPD_35`, `RPD_31` | 450 | спільний денний ліміт перевірок на модель |
| `IP_PER_MIN`, `IP_PER_DAY` | 6 / 150 | ліміти для одного пристрою |
| `MAX_ANSWER` | 1500 | максимальна довжина відповіді |
| `ALLOWED_ORIGINS` | `*` | звідки дозволені запити |

Після зміни виконайте `npx wrangler deploy` ще раз. Скільки перевірок лишилося, показує `/status`.
